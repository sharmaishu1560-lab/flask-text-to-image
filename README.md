\# Flask Text-to-Image Generator



A web-based AI text-to-image application built using Python, Flask, HTML, CSS, JavaScript, and the OpenAI API.



The application allows users to enter a text prompt and generate an AI-created image.



\## Features



\- Simple web-based interface

\- Text prompt input

\- AI image generation

\- Flask backend

\- OpenAI API integration

\- Generated image display

\- Environment variable support

\- Basic error handling



\## Technologies Used



\- Python

\- Flask

\- OpenAI API

\- HTML

\- CSS

\- JavaScript

\- python-dotenv
